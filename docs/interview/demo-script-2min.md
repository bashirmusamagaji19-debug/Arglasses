# 2 分钟 Demo 脚本

> 目标：展示“AI 眼镜视觉记忆 RAG 助手”不是一次性图片问答，而是能积累、检索和追问历史场景的系统原型。

## 0:00 - 0:15 项目定位

**操作：** 打开 Streamlit demo。

**讲解：**

> 这是一个面向 AI 眼镜场景的视觉记忆 RAG 助手。它模拟眼镜第一视角输入，把每次看到的内容、用户问题、OCR 文本和视觉回答沉淀成记忆，后续可以围绕历史场景继续追问。

## 0:15 - 0:40 当前图片问答

**操作：**

1. 在“当前输入”区域上传一张包含鼠标、屏幕或桌面物品的图片。
2. 输入：

```text
我刚才看到了什么？
```

3. 点击“提交问题”。

**讲解：**

> 这里跑的是一次完整视觉问答 pipeline：图片先进入 OCR provider 提取文字，再进入 VLM provider 生成视觉回答。系统随后用 summary provider 把问题、回答和 OCR 文本整理成场景摘要。

## 0:40 - 1:00 记忆写入和时间线

**操作：**

滚动到“记忆时间线”，展开刚才新增的记录。

**讲解：**

> 每次交互都会写成一条 MemoryEvent，保存在 SQLite 里。它不是只保存一句回答，而是保存用户问题、视觉回答、场景摘要、OCR 文本、图片路径和延迟数据。这样后续可以按时间线回看，也可以做语义检索。

## 1:00 - 1:25 历史检索

**操作：**

在“历史检索”中输入关键词，例如：

```text
鼠标
```

查看召回记录。

**讲解：**

> 历史检索不是只查标题，而是把 question、answer、scene_summary 和 OCR 文本一起作为可检索内容。当前默认后端是 Chroma，系统用 memory id 把 Chroma 的召回结果回表到 SQLite，拿到完整记忆。

## 1:25 - 1:50 RAG 历史问答

**操作：**

在“历史记忆问答”中输入：

```text
鼠标是什么颜色的？
```

点击“基于记忆回答”。

**讲解：**

> 这里就是 RAG 闭环：用户不是在搜索“鼠标”这个词，而是在问历史记忆问题。系统先用 Chroma 召回 top-k 相关记忆，再由 RAG answer provider 基于这些上下文生成回答。比如它会总结鼠标主要是黑色的，如果历史中还出现过银灰色鼠标，也会一起说明。

**操作：**

指向“使用的历史记忆”列表。

**讲解：**

> 这里保留了回答使用的历史记忆，相当于证据列表。面试时我可以解释每个回答来自哪些 memory event，而不是黑盒生成。

## 1:50 - 2:00 收尾

**讲解：**

> 当前版本已经跑通手机/图片输入、OCR/VLM provider、SQLite 记忆库、Chroma 检索和 RAG 历史问答。后续会继续补 ASR 语音输入、隐私模式、延迟面板和硬件端 HTTP 上传，让它更接近真实 AI 眼镜系统。

## 备用命令

如果现场不方便操作 UI，可以运行 smoke：

```powershell
.\.venv\Scripts\python.exe scripts\rag_smoke.py
```

预期输出包括：

```text
question: 鼠标是什么颜色的？
answer: 根据历史记忆，鼠标主要是黑色的；另外也出现过银灰色的鼠标。
contexts: 2
```
